# IT-жобаның талаптарын басқару

## Жоба туралы

Бұл репозиторий «IT-жобаларды басқару» пәні бойынша оқу жобасын орындау үшін құрылды.

Жобаның тақырыбы: «IT-жобаның талаптарын басқару».

Жобаның мақсаты — IT-жоба шеңберінде талаптарды жинау, талдау, құжаттау, басымдықтарын анықтау және талаптарға енгізілетін өзгерістерді бақылау процесін ұйымдастыру.

## Жобаны басқару моделі

Жобаны орындау үшін Agile / Scrum тәсілі таңдалды.

Таңдау себептері:
- өзгеретін талаптарға жылдам бейімделу;
- жобаны қысқа итерациялар арқылы орындау;
- пайдаланушылардан тұрақты кері байланыс алу;
- талаптарды backlog арқылы басқару;
- MVP нұсқасын ерте дайындау мүмкіндігі.

## Жобаның негізгі артефактілері

- ADR — жобада қабылданған шешімдерді тіркеу;
- Product Backlog;
- User Stories;
- Acceptance Criteria;
- Story Map;
- нефункционалдық талаптар;
- стейкхолдерлер матрицасы;
- коммуникация жоспары.

## Жобадағы атау ережелері

Тармақтар (Branches):
- feature/тапсырма-атауы
- fix/қате-атауы
- docs/құжат-атауы

Тапсырмалар:
- TASK-001
- TASK-002
- TASK-003

## Тапсырмалардың статустары

- Backlog — жоспарланған тапсырмалар;
- Ready — орындауға дайын;
- In Progress — орындалып жатыр;
- Review — тексерілуде;
- Done — аяқталды.
